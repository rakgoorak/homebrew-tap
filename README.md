# Homebrew Tap for SuperAi & RAKKYXD

Install **SuperAi & RAKKYXD** on macOS (13+ Apple Silicon or Intel):

```bash
brew install --cask rakgoorak/tap/superai-rakkyxd
```

Update to the latest version:

```bash
brew upgrade --cask superai-rakkyxd
```

- Website: https://rakgoorak.github.io/SuperAi-RAKKYXD/
- Source code: https://github.com/rakgoorak/SuperAi-RAKKYXD
